📦 Sistema de Gestión de Productos
Trabajo Práctico — UTN Facultad Regional General Pacheco

📋 Descripción
Aplicación de consola desarrollada en C++ para la gestión y administración de un catálogo de productos. Implementa operaciones básicas sobre una colección de productos usando programación orientada a objetos.

⚙️ Funcionalidades
Alta de productos — Registro de nuevos productos en el sistema
Baja de productos — Eliminación de productos existentes
Modificación — Edición de datos de productos registrados
Listado — Visualización del catálogo completo

🛠️ Tecnologías utilizadas
Lenguaje: C++
Paradigma: Programación orientada a objetos
Entorno: Visual Studio / g++

🚀 Cómo ejecutar el proyecto
Clonar el repositorio:
```bash
   git clone https://github.com/mqr-ina/Gestion-de-Productos.git
   ```
Compilar y ejecutar:
```bash
   g++ main.cpp -o gestion
   ./gestion
   ```

📚 Conceptos aplicados
Clases y objetos en C++
Encapsulamiento y abstracción
Manejo de colecciones y estructuras de datos
